## 소개

통계학을 전공한 예비 데이터 분석가의 포트폴리오입니다.
Home · About Me · Projects 슬라이드로 구성했고, 프로젝트 카드를 클릭하면 상세 페이지가 열립니다.

## 구성

```
├─ index.html     # 슬라이드 구조 (Home / About Me / Projects)
├─ style.css      # 디자인
├─ script.js      # 프로젝트 카드·상세 페이지 생성, 인터랙션
├─ projects/      # 프로젝트별 데이터 파일 (내용만 고치면 화면에 반영)
├─ images/        # 프로필·프로젝트 이미지
└─ font/          # 직접 지정한 영문 제목 폰트
```

## 사용 기술

HTML · CSS · JavaScript (GitHub Pages로 배포)

## 개발 메모
- 브러우저 인쇄(Ctrl + P → PDF로 저장)   
- 인쇄 창에서 '배경 그래픽' 켜기 → 머리글 및 바닥글은 꺼야 함
